# AI 成果檔案生成流程｜老師實用操作指南（ChatGPT Image 2.0）

在使用 AI 製作成果檔案時，最常見的問題是：

- 圖很好看，但文件不好用（變成海報、資訊不清楚）

這份指南聚焦使用 **ChatGPT Image 2.0** 生成「可閱讀、可列印、可評量」的課程學習成果檔案。  
關鍵不在工具本身，而在「提示詞結構」。

---

## 一、先確認產出類型（避免做成海報）

```plaintext
生成一份「A4直式課程學習成果檔案」，可閱讀的學習歷程文件
```

> 這一句一定要寫，先鎖定文件屬性。

---

## 二、建立內容骨架（先給內容）

```plaintext
【基本資料】
【主題設定】
【成果概述】
【學習內容】
【心得與省思】
```

> 文字越完整，排版越穩。

---

## 三、加入版面限制（關鍵步驟）

```plaintext
【版面設計要求】
- A4直式
- 左右分欄
- 卡片式區塊
- 圖片不超過40%
- 文字清楚可閱讀
```

> 這一步是避免變成「漂亮但不能讀」。

---

## 四、加入風格來源（兩種方式）

### 方法 A：參考圖片

```plaintext
請參考上傳圖片的風格（Art portfolio 設計排版風格）
```

### 方法 B：YAML 控制（進階）

```yaml
style:
  layout: "portfolio grid"
  color_palette:
    primary: ["#FF00AA", "#00D1FF", "#6A00FF"]
  typography:
    title: "bold large"
  visual_elements:
    shapes: ["rounded card", "gradient block"]
```

---

## 五、整合控制語句（避免跑版）

```plaintext
請參考圖片風格，並確保整體設計符合上述版面與內容結構
```

---

## 六、圖片需求補充

```plaintext
需包含：
- 馬克杯設計主圖
- 設計草圖
- 情境 mockup
```

---

## 七、範例一（日本文化｜清楚可讀版）

特點：圖文平衡、資訊清楚、適合初次使用。

```plaintext
請生成一份A4直式課程學習成果檔案。

主題：日本文化馬克杯設計
內容包含：成果概述、學習內容、心得省思

版面要求：
- 左右分欄
- 卡片式區塊
- 圖片不超過40%

風格：
- 日系編輯風
- 色彩簡潔（紅、藍、米白）
- 插畫＋少量攝影

圖片：
- 馬克杯（富士山、櫻花）
- 草圖
- 使用情境

輸出：可列印A4、高解析
```

適合：
- 初次操作
- 需要穩定成果

---

## 八、範例二（墨爾本塗鴉｜設計提案風）

特點：設計感強，但仍維持可閱讀。

```plaintext
請參考上傳圖片風格（Art portfolio），
生成A4直式課程學習成果檔案。

主題：墨爾本塗鴉巷文化馬克杯

內容：
- 成果概述
- 學習內容（條列）
- 心得省思（完整段落）

版面：
- 左右分欄
- 卡片式設計
- 圖片不超過40%

風格：
- 漸層色（紫、藍、粉）
- 幾何切割
- 局部塗鴉元素（不干擾文字）

圖片：
- 塗鴉風馬克杯
- 設計發展圖
- 情境 mockup

輸出：高解析、可列印
```

適合：
- 已熟悉操作
- 想提升設計感

---

## 最後提醒

- 沒有限制版面 → 會變海報  
- 沒有內容 → 會變裝飾圖

提示詞的本質不是「描述畫面」，而是「定義結構＋控制結果」。
